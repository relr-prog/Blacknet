# Security policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue or pull
request. Use GitHub's **Report a vulnerability** feature on the repository's
Security tab to send a private report. If private vulnerability reporting is
not available, contact the repository maintainers using the address listed in
the repository metadata and ask for a private channel before sending technical
details.

Include the affected component and version or commit, the conditions needed to
reproduce the issue, its security impact, and a minimal proof of concept when
safe to share. Do not include real credentials, personal data, or third-party
data. Please allow maintainers time to investigate and coordinate a fix before
public disclosure.

## Scope and support

BlackNet is experimental software. Security fixes are handled on a best-effort
basis; no response time or supported-version window is guaranteed. A report
does not mean that a particular privacy or security property is guaranteed.
See the [threat model](README.md#threat-model) for documented limitations.
